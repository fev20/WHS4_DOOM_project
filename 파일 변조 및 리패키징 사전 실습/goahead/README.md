# goahead 웹루트 수정

카메라의 관리자 페이지에 접속했지만 화면이 정상적으로 표시되지 않았습니다. 웹 서버인 `goahead`가 페이지 파일을 찾는 기준 폴더인 **웹루트**를 제대로 지정하지 못하는 문제였습니다. 실제 로그인 화면인 `home.htm`과 관련 파일은 `/etc/webs`에 있었습니다.

![관리자 페이지 접속 시 나타난 Not Found 오류](./img/image%201.png)

PC에서 추출한 펌웨어로 웹 서버를 실행했을 때의 화면입니다. 브라우저에 로그인 화면 대신 `Access Error: Not Found`가 표시되었습니다. 오른쪽 터미널의 `symMax` 메시지는 별도의 인증 초기화 관련 오류이며, 이 문서에서는 페이지 파일을 찾지 못하는 웹루트 문제를 다룹니다.

## 1. 웹루트 지정하기

펌웨어를 풀어 놓은 폴더에서 `etc/webs/route.txt`를 엽니다. 이 파일은 웹 요청을 어떻게 처리할지 정하는 설정 파일입니다.

맨 마지막에 있는 다음 줄을 찾습니다.

```text
route uri=/
```

뒤에 `dir=/etc/webs`를 추가합니다.

```text
route uri=/ dir=/etc/webs
```

`dir=/etc/webs`는 해당 경로로 들어온 요청에 대해 `/etc/webs`에서 페이지 파일을 찾도록 지정하는 설정입니다. `/etc/webs`는 PC에서 펌웨어를 풀어 놓은 폴더의 경로가 아니라, 카메라 내부의 경로입니다.

## 2. 수정 결과

수정한 설정으로 웹 서버를 실행한 뒤 관리자 페이지가 정상적으로 표시되는 것을 확인했습니다. 이 설정 변경으로 웹루트를 명시할 수 있어, 페이지 표시 문제를 해결하기 위한 바이너리 패치는 필요하지 않았습니다.

웹 요청으로 DOOM을 실행하기 위한 바이너리 패치는 [둠 트리거 구현](../../DOOM%20포팅%20구현/둠%20트리거%20구현/README.md)에서 설명합니다.
