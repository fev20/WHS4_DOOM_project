# 펌웨어 추출
프로젝트를 시작하기 위해서 Jooan 홈 카메라에서 펌웨어 추출을 하였습니다.
해당 과정은 총 2가지 도구를 사용해서 진행하였으며, 2장에서는 칩 클램퍼를 이용해 추출한 과정을, 3장에서는 테스트 니들을 이용해서 추출하는 과정을 정리했습니다.
