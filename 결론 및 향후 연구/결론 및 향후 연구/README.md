# 결론 및 향후 연구
## 결론
본 프로젝트는 JOOAN C9TS IP 카메라의 펌웨어를 획득하고 파일시스템, 부팅 과정 및 서비스 구성을 분석한 뒤, 확인한 실행 환경을 바탕으로 DOOM을 장치에 이식했습니다. MIPS용 실행 파일을 빌드하고, Mongoose와 WebSocket을 이용해 게임 화면을 브라우저로 전송하며 키 입력을 장치에 전달하는 구조를 구현하였습니다.
그 결과 실제 장치에서 DOOM 화면을 확인하고 브라우저로 게임을 조작하는 데 성공하였고, 이는 작은 임베디드 장치인 IP 카메라에서도 실행 환경 분석과 원격 입출력 구현을 통해 응용 프로그램을 구동할 수 있음을 보여줍니다.

## 향후 연구
[결과 분석 및 한계](/실험%20및%20결과/결과%20분석%20및%20한계/README.md)에서 나왔던 한계점을 개선하기 위해 다음과 같은 향후 연구를 계획중입니다.

### 1. 기존 홈캠 앱을 통한 DOOM 출력

현재는 브라우저로만 볼 수 있는 DOOM 화면을 기기 본래의 홈캠 앱에서 바로 볼 수 있게 하는 것을 목표로 합니다. 이를 위해서는 cam720과 통신하는 바이너리를 분석해 카메라의 비디오 스트림을 확인하고 이를 가로채는 방식으로 DOOM 화면을 cam720 앱에 출력하는 방식으로 계획중입니다.

### 2. 글리칭을 통한 Secure Boot 기기로의 확장

글리칭 기법으로 무결성 검증을 우회해 Secure Boot가 적용된 고가형 기기에서도 수정한 펌웨어를 실행시킬 수 있도록 하는 것을 목표로 합니다.

고가형 기기는 Secure Boot로 인해 수정 펌웨어가 부팅 단계에서 거부되므로 전압이나 클럭에 순간적으로 결함을 주입해 서명 검증 과정을 실패·우회시키는 방식을 연구합니다.
